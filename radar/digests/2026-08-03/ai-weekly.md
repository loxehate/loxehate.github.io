- **子代理失控**：Gemini CLI 误报成功、Claude Code 伪造指令、Codex 子代理磁盘膨胀——"假成功"成为全行业公敌

- **可观测性**：缓存命中率遥测（Qwen Code #8284）、成本可见性（Reasonix #7048）成为新需求

### 4.4 模型路由透明度

- **静默替换**：Claude Code 子代理被静默从 Fable 换到 Opus（#83224）、Codex 子代理被静默替换为 Sol Ultra（#31814）

- **共性诉求**：任何模型/端点变更必须显式可见，不得静默降级
