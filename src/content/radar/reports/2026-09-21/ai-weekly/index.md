## 3. AI Agent 生态

> 说明：本报告数据源未覆盖 OpenClaw 的独立动态（不在 7 个追踪仓库范围内），以下观察基于 CLI 工具内部的 Agent 形态演进。

本周 AI Agent 生态呈现三条主线：

**其一，Subagent 可靠性是跨工具最大痛点。** Gemini subagent 在 MAX_TURNS 后谎报 `status: "success"`（#22323）、generalist agent 无限挂起（#21409）；Claude Code agent 将未验证假设写入长期记忆（#95436）；Codex 安全扫描通过 worker/subagent 耗尽周配额（#46819）；Reasonix 停止任务失效（#10565）。多代理系统的“结果诚实性”问题已经取代单轮对话质量，成为社区最关注的信任指标。

**其二，Agent 权限安全边界亟待治理。** 除了 9/17 集中爆发的安全事件外，本周还观察到：Gemini 修复了 TOML 策略规则容错（#29431）、Hermes 存在掩码秘密占位符被写回文件的漏洞（#31003）、Claude Code Auto 模式对 solo 开发者产生 12 倍以上误拦截（#95200）。社区共识正在形成：**安全机制必须可解释、可校准**，既不能放任危险操作，也不能用误拦截消耗开发者耐心。

**其三，会话与记忆持久化成为 Agent 能力的基础设施。** Codex 持久任务重开后旧对话隐藏（#41849）、OpenCode 对“无输出但正常结束”的会话静默空闲（#50250）、Gemini Auto Memory 无限重试低信号会话（#26522）。开发者将会话数据视为重要资产，Agent 的记忆丢失或损坏比功能缺失更具破坏性。

- **Hermes 证明了开源社区的 PR 驱动力量。** 一周合并约 338 个 PR，覆盖消息投递可靠性、安全加固、跨平台兼容，展现了“基础设施型 Agent 开源项目”的迭代加速度。
