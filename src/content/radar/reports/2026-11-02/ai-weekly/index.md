## 2. CLI 工具进展

### Claude Code（Anthropic）
- **版本**：本周发布 v2.1.311、v2.1.312、v2.1.314、v2.1.316，保持稳定版周度迭代节奏。
- **关键变化**：侧重安全沙箱、企业级权限控制（IdP 组级访问、多账户 Connector）及成本管控；Mods 插件系统社区讨论热度极高；Headless/自动化模式的 Token/费用审计需求强烈。
- **痛点**：会话掉落/丢失、Max 5x 使用量异常激增、Fable 5 安全分类器误报导致静默模型降级、子代理虚假成功/挂起。

### OpenAI Codex（OpenAI）
- **版本**：本周发布 rust-v0.165.0 稳定版，以及 0.166.0-alpha.3 至 0.167.0-alpha.3 多个 Alpha 版本，Rust 端迭代最为激进。
- **关键变化**：自动化机器人提交 PR 密集（多为 CLOSED），聚焦 Windows/macOS 桌面端稳定性、VS Code 扩展兼容、MCP/插件生命周期管理。
- **痛点**：桌面端渲染器内存泄漏（4–7 GB）、后台轮询导致 Token 浪费、Windows 与 WSL 路径映射、跨区支付失败。

### Gemini CLI（Google）
- **版本**：本周多次发布夜间版（v0.67.0-nightly 系列）及 preview.0，保持高频夜间构建节奏。
- **关键变化**：通过 ACP 协议推进 Zed/JetBrains/VS Code 深度集成，支持客户端干预运行中会话；AST 感知代码读取与浏览器代理能力持续增强。
- **痛点**：子代理达到 MAX_TURNS 后仍报告成功、通用代理无限挂起、工具数 >128 触发 400 错误、Wayland 下浏览器子代理失败。

### DeepSeek Reasonix
- **版本**：本周发布 v2.52.0、v2.53.1、v2.54.0、v2.56.1（Studio + CLI 双端同步），迭代节奏稳定。
- **关键变化**：聚焦桌面端 Studio 体验、多会话并发、网络层稳定性及隐私路径；团队协作功能部分仍在审核中。
- **痛点**：移动端长会话接口超时、Linux 安装脚本失败、GPU 误禁用、跨端会话同步。

### OpenCode
- **版本**：本周发布 v2.2.0 及 v2.2.3/v2.2.4/v2.2.5 连续小版本，PR 活动极高（50+）。
- **关键变化**：推进 V2 核心稳定性、媒体资源按需加载、权限交互优化、桌面端配对；与 Claude Code 互联成为差异化亮点。
- **痛点**：SSE4.2 兼容性、v2 服务迁移、AI 循环鲁棒性、长会话存储占用。

### Hermes（NousResearch）
- **版本**：本周无新版本发布，但 PR 更新数持续在 50+，社区活跃度高。
- **关键变化**：聚焦 Discord 网关稳定性、Kanban 调度、审批安全、多 Profile 正确性及跨平台 IM 集成（Telegram/Discord/Slack）。
- **痛点**：platform_toolsets 空列表语义歧义、Python 3.14 Android wheel 缺失、会话恢复字段缺失。

### OpenClaw
- **版本**：本周处于 Beta 阶段，发布 v2026.10.8 / v2026.9.35 / v2026.10.10-beta.4/beta.5。
- **关键变化**：网关恢复、跨平台路径处理、IM 渠道扩展、MLX 缓存优化、Web UI 性能提升。
- **痛点**：Gateway 恢复可靠性、跨平台路径兼容、模型输出固化用词与越界执行审计。

### DeepSeek Harness
- **状态**：本周基本无社区活动（Issues/PR 均为 0），仅有低频候选版本迭代（dsh-v0.2.1-rc.5 等），处于低频维护状态。

## 3. AI Agent 生态

本周 AI Agent 生态围绕 **OpenClaw** 及同赛道多代理协作项目呈现以下特征：

- **OpenClaw**：作为网关型 Agent 项目，本周重点优化跨平台路径与 IM 渠道扩展，PR 活跃度（50+）显著高于 Issue 更新数（7 条），表明社区更侧重代码贡献而非问题反馈，Beta 阶段稳定性仍是核心挑战。
- **多代理协作稳定性**：Claude Code、Gemini CLI、OpenCode、OpenClaw 社区均反映子代理未继承全局规则（AGENTS.md）、子代理挂起或状态误报（报 success 实则中断）、多会话/多子代理锁竞争导致阻塞等问题，已成为行业共性瓶颈。
- **MCP/插件生态**：Claude Code、Gemini CLI、Hermes 均出现 MCP 服务器生命周期管理、长参数截断、工具数阈值限制（>128 触发 400 错误）等问题，插件互操作性亟待标准化。
- **跨端会话迁移**：Claude Code 与 Claude Desktop、OpenCode 桌面终端与服务器重启后的历史保留、Hermes 远程后台/移动端会话在桌面端无法恢复（session.resume 返回 not_found）等跨端体验不一致问题集中暴露。

## 4. 开源趋势

基于本周 GitHub 及 AI 社区活动，主要技术方向包括：

1. **会话状态持久化与跨端同步**：会话掉落、跨端会话同步、额度重置后自动续会成为各 CLI 工具社区最高频诉求，状态管理正从“可选功能”升级为“核心基础设施”。
2. **计费透明度与成本审计**：Token/费用审计日志、异常消耗回滚申诉、Plus/Max 订阅独立额度等需求集中爆发，企业级成本可见性成为采购决策关键因素。
3. **ACP 协议与 IDE 深度集成**：Gemini CLI 通过 ACP 协议嵌入主流 IDE，支持客户端干预运行中会话，IDE 不再仅是代码编辑器，正演进为 AI Agent 的控制面板。
4. **沙箱策略与开发者自主权**：Claude Code、OpenAI Codex、OpenCode 社区均呼吁在开发环境下提供“Opt-in”机制，细粒度沙箱审批与 Auto 模式白名单成为安全与效率的平衡点。
5. **夜间构建与高频小迭代**：Gemini CLI、OpenAI Codex（Rust 端）、OpenCode 均采用夜间版/Alpha 版快速迭代，开源项目发布节奏正向“持续交付”靠拢。

## 5. HN 社区热议

*注：以下基于本周各日报告中反映的社区情绪与讨论热点综合判断。*

- **核心话题**：AI CLI 工具的“稳定性债务”问题。开发者普遍认为功能堆叠速度超过底层打磨速度，子代理状态不可信、会话随机丢失、计费异常等问题严重影响生产环境可用性。
- **社区情绪**：谨慎乐观。开发者认可多代理协作和 IDE 集成的前景，但对“静默模型降级”“安全误报导致功能受限”等缺乏透明度的行为表达不满，要求厂商提供误报申诉通道与白名单机制。
- **争议焦点**：自动更新强制重启导致远程会话丢失，以及桌面端与 TUI 端体验差距较大，部分用户主张回归“可控的手动更新”模式。
